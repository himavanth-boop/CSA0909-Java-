B2.1 – Identify an Adversarial Input (2 Marks)
An adversarial input is intentionally designed data that exposes weaknesses in a file-processing application.
Example: A CSV record containing a comma inside the student name.
P1001,192311001,Arun,Kumar,12,Central Bus Stop,2027-06-30,4500.00
The program expects seven fields, but this record contains eight fields because the name contains a comma.
Problems:
1.	Incorrect field count.
2.	Wrong field mapping.
3.	Parsing errors.
4.	Incorrect student information.
B2.2 – Demonstrate the Failure (1 Mark)
Java Code:
public class CSVTest {
    public static void main(String[] args) {

        String record =
            "P1001,192311001,Arun,Kumar,12,Central Bus Stop,2027-06-30,4500.00";

        String[] fields = record.split(",");

        System.out.println("Number of fields: " + fields.length);

        if (fields.length != 7) {
            System.out.println("Invalid record format");
        }
    }
}
Expected Output:
Number of fields: 8
Invalid record format
B2.3 – Improve the Design (2 Marks)
Use a proper CSV parser that supports quoted fields instead of splitting records directly using commas.
Correct CSV Record:
P1001,192311001,"Arun,Kumar",12,"Central Bus Stop",2027-06-30,4500.00
Improved Java Approach using Apache Commons CSV:
import org.apache.commons.csv.*;
import java.io.*;

public class SafeCSVReader {
    public static void main(String[] args) throws IOException {

        try (CSVParser parser = CSVParser.parse(
                new File("passes.csv"),
                java.nio.charset.StandardCharsets.UTF_8,
                CSVFormat.DEFAULT)) {

            for (CSVRecord record : parser) {

                if (record.size() != 7) {
                    System.out.println("Invalid record skipped");
                    continue;
                }

                System.out.println("Pass ID: " + record.get(0));
                System.out.println("Student: " + record.get(2));
            }
        }
    }
}
Conclusion: Using a proper CSV parser, validating field counts and handling malformed records prevents incorrect data processing and improves application reliability.
