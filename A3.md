A3.1 – Identify the Pattern (2 Marks)
The suitable design pattern is the Data Access Object (DAO) Pattern.
The DAO pattern separates database operations from business logic. It provides a separate class to perform database operations such as insert, update, delete and retrieve.
Main components:
1.	Model Class: Represents the data.
2.	DAO Interface: Defines database operations.
3.	DAO Implementation: Contains SQL queries and database logic.
4.	Service Class: Handles business logic and communicates with the DAO.
Example:
interface StudentDAO {
    void addStudent(Student student);
    Student getStudent(int id);
    void updateStudent(Student student);
    void deleteStudent(int id);
}
A3.2 – Design the DAO Structure (2 Marks)
Student.java
public class Student {
    int id;
    String name;

    public Student(int id, String name) {
        this.id = id;
        this.name = name;
    }
}
StudentDAO.java
public interface StudentDAO {
    void addStudent(Student student);
    Student getStudent(int id);
}
StudentDAOImpl.java
import java.sql.*;

public class StudentDAOImpl implements StudentDAO {

    Connection con;

    public StudentDAOImpl(Connection con) {
        this.con = con;
    }

    public void addStudent(Student student) {
        String sql = "INSERT INTO students VALUES (?, ?)";

        try (PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setInt(1, student.id);
            ps.setString(2, student.name);
            ps.executeUpdate();
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }

    public Student getStudent(int id) {
        String sql = "SELECT * FROM students WHERE id = ?";

        try (PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setInt(1, id);

            ResultSet rs = ps.executeQuery();

            if (rs.next()) {
                return new Student(
                    rs.getInt("id"),
                    rs.getString("name")
                );
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }

        return null;
    }
}
A3.3 – Advantages of DAO Pattern (1 Mark)
•	Separates database logic from business logic.
•	Improves code reusability and maintainability.
•	Makes database changes easier without modifying the application logic.
•	Simplifies testing by allowing DAO implementations to be replaced.
Conclusion: The DAO pattern provides a structured way to manage database operations and improves the maintainability of Java applications
