A5.1 – Identify File Handling Risks (2 Marks)
The following problems may occur while storing bus-pass records in a file:
1.	Data Corruption: An application crash during writing may leave incomplete records.
2.	Duplicate Records: The same bus-pass ID may be inserted multiple times.
3.	Concurrent Access: Multiple users writing simultaneously may overwrite or corrupt data.
4.	Missing File: The application may fail if the required file does not exist.
5.	Invalid Data: Incorrect field values may cause parsing errors.
A5.2 – Design Safety Measures (1 Mark)
The following measures improve file-handling reliability:
•	Use try-with-resources to close files automatically.
•	Validate records before writing them.
•	Check for duplicate pass IDs before insertion.
•	Use file locking to prevent simultaneous writes.
•	Write updates to a temporary file and replace the original only after successful completion.
•	Maintain backup copies for recovery.
Java Example:
import java.io.*;

public class SafeFileWrite {

    public static void main(String[] args) {

        try (BufferedWriter writer = new BufferedWriter(
                new FileWriter("passes.txt", true))) {

            writer.write("P1001,192311001,Arun Kumar,12");
            writer.newLine();

            System.out.println("Record saved successfully.");

        } catch (IOException e) {
            System.out.println("File error: " + e.getMessage());
        }
    }
}
A5.3 – Prevent Duplicate Records (1 Mark)
Before inserting a new bus-pass record, check whether its Pass ID already exists.
Pseudocode:
ALGORITHM AddPass(pass)

BEGIN
    OPEN the file for reading

    WHILE records are available
        READ existing record

        IF existing.passID = pass.passID
            DISPLAY "Duplicate Pass ID"
            RETURN
        END IF
    END WHILE

    CLOSE the file

    OPEN the file in append mode
    WRITE the new pass record
    CLOSE the file

    DISPLAY "Pass added successfully"
END
Conclusion: Proper validation, duplicate checking, file locking and backup mechanisms help maintain data correctness and prevent accidental data loss.
