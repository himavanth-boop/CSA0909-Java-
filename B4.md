B4.1 – Compare File Storage and Database Storage (2 Marks)
Parameter	File Storage	Database Storage
Data organization	Text or binary files	Tables and rows
Searching	Sequential scanning	Indexed searching
Data security	Limited file-level protection	Authentication and access control
Concurrent access	Requires file locking	Supports concurrent transactions
Data consistency	Manual validation	Constraints and transactions
Scalability	Suitable for smaller datasets	Suitable for large datasets
Maintenance	Simple for small applications	Requires database management
B4.2 – Select the Appropriate Storage Method (2 Marks)
For the university bus-pass management system, MySQL database storage is the recommended solution.
Reasons:
1.	It supports thousands of student bus-pass records.
2.	It provides fast searching using indexes.
3.	It prevents duplicate pass IDs using primary-key constraints.
4.	It supports concurrent access by multiple transport-office employees.
5.	It provides transaction management for reliable data updates.
6.	It supports secure database access through authentication and permissions.
Recommended Database Design:
CREATE DATABASE transport;

USE transport;

CREATE TABLE bus_pass (
    pass_id VARCHAR(20) PRIMARY KEY,
    register_number VARCHAR(20) NOT NULL,
    student_name VARCHAR(100) NOT NULL,
    route_number INT NOT NULL,
    boarding_stop VARCHAR(100),
    validity_date DATE NOT NULL,
    amount_paid DOUBLE NOT NULL
);
B4.3 – Final Engineering Decision (1 Mark)
The file-based approach is suitable for small applications, backups and simple data storage. However, the university bus-pass management system requires reliable searching, concurrent access, duplicate prevention and secure record management.
Therefore, MySQL with JDBC and PreparedStatement is the most appropriate solution. Batch processing can be used when inserting large numbers of records, while file storage can be retained for exporting and backing up data.
Conclusion: Database storage provides better reliability, scalability, security and data consistency for the university bus-pass management system.
