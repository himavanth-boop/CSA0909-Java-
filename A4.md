A4.1 – Identify Serializable Data (2 Marks)
Serialization is the process of converting an object into a byte stream so that it can be stored in a file or transferred over a network.
In the bus-pass application, the following fields should be serialized:

Field	Serialize?	Reason
Pass ID	Yes	Identifies the bus pass
Student Register Number	Yes	Identifies the student
Student Name	Yes	Stores student details
Route Number	Yes	Stores assigned route
Boarding Stop	Yes	Stores boarding location
Validity Date	Yes	Stores pass validity
Amount Paid	Yes	Stores payment information
Database Connection	No	Runtime resource, not persistent data
File Handle	No	Cannot be meaningfully restored through serialization

A4.2 – Implement Serialization (1 Mark)
Java Code:
import java.io.*;
import java.time.LocalDate;

class BusPass implements Serializable {

    private static final long serialVersionUID = 1L;

    String passId;
    String registerNumber;
    String name;
    int routeNumber;
    String boardingStop;
    LocalDate validityDate;
    double amountPaid;

    public BusPass(String passId, String registerNumber,
                   String name, int routeNumber,
                   String boardingStop,
                   LocalDate validityDate, double amountPaid) {

        this.passId = passId;
        this.registerNumber = registerNumber;
        this.name = name;
        this.routeNumber = routeNumber;
        this.boardingStop = boardingStop;
        this.validityDate = validityDate;
        this.amountPaid = amountPaid;
    }
}

public class BusPassSerialization {

    public static void main(String[] args) throws Exception {

        BusPass pass = new BusPass(
            "P1001", "192311001", "Arun Kumar",
            12, "Central Bus Stop",
            LocalDate.of(2027, 6, 30), 4500.00
        );

        ObjectOutputStream out = new ObjectOutputStream(
            new FileOutputStream("buspass.ser")
        );

        out.writeObject(pass);
        out.close();

        System.out.println("Bus pass serialized successfully.");

        ObjectInputStream in = new ObjectInputStream(
            new FileInputStream("buspass.ser")
        );

        BusPass restored = (BusPass) in.readObject();
        in.close();

        System.out.println("Restored Pass ID: " + restored.passId);
        System.out.println("Student Name: " + restored.name);
    }
}

A4.3 – Security Considerations (1 Mark)

•	Never deserialize data from untrusted sources because malicious serialized objects may execute dangerous code through gadget chains.
•	Validate data after deserialization.
•	Avoid serializing sensitive information such as passwords.
•	Use access controls and encryption when storing confidential records.
•	Use transient for fields that should not be serialized.

Example:
transient String password;
Conclusion: Serialization is useful for saving and restoring Java objects, but only appropriate data should be serialized, with proper security precautions.
